Learn how to import customer data into Shopify using CSV files to prepare for a smooth subscription migration to Loop.

If you're migrating from a non-Shopify platform, you can bring your customer information into Shopify using a CSV file. Shopify allows you to upload customer details in bulk through its admin panel using a predefined CSV format. This helps ensure a smooth transition before you begin setting up subscriptions with Loop.  
​

You can only import customer CSV files that are 1 MB or smaller. To get around this restriction, you can use multiple CSV files to import your customer profiles.

* * *

# Exporting customer data

Your export process will depend on the platform you're currently using. The goal is to export basic customer information like name, email, and address into a CSV format that matches Shopify's import structure.

Once exported, review and format the file according to [Shopify’s customer CSV template](https://help.shopify.com/en/manual/customers/import-export-customers) before uploading.  
​

# Importing customer data in Shopify

**To import your customer list into Shopify, follow these steps to complete the process.**

1.  Log in to your Shopify admin.  
    ​
    
2.  Navigate to **Customers > Import**.  
    ​
    
3.  Upload your customer CSV file using Shopify's native import tool.
    

This allows Shopify to recognize these customers, making them eligible for subscription data migration via Loop.
