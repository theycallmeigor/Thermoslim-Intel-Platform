Learn how to migrate active subscriptions from Smartrr to Loop seamlessly with expert support and zero disruption to your customers.

If you’re currently using **Smartrr** and want to move to **Loop**, our migration team can help you transfer all your active subscriptions smoothly with zero disruption to your customers.

* * *

# Prerequisites

Before we can begin your migration, we need to make sure these things are in place.

*   **Loop widget is live** on the storefront, and the account page points to the Loop customer portal.
    
*   **Smartrr API token** is created with **write access to all scopes** and shared with the Loop team.
    
*   **Customer portal** in Smartrr is set to **disabled** prior to migration.
    
*   **Notifications** in Smartrr are set to **disabled** prior to migration.  
    ​
    

Since Smartrr uses Shopify’s native subscription APIs, no payment migration is needed.

Ensure your API token has write access to the subscription object, or step (4) of the migration will fail.

  
​

# Migrate from Smartrr

Once the prerequisites are complete, follow these steps to complete the process.

1.  Email us at **[\[email protected\]](/cdn-cgi/l/email-protection#24575154544b565064484b4b54534b564f0a474b)** or **[\[email protected\]](/cdn-cgi/l/email-protection#86ebefe1f4e7f2efe9e8f5c6eae9e9f6f1e9f4eda8e5e9)** with the required details.  
    ​
    
2.  Use the following subject and template for faster processing.  
    ​
    

**Subject**: {Brand Name} Migration from Smartrr → Loop  
​  
​**Body**:  
​  
​**Source platform**: Smartrr  
​  
​**Smartrr API key**: {insert API token}

  
​**Note:** Our onboarding/migration team will reply with available migration dates.

  
​

# White glove migration walkthrough

On your scheduled migration date, our team will:

1.  Export your subscription data from Smartrr using the shared API token.  
    ​
    
2.  Import the data into your Loop store.  
    ​
    
3.  Cancel all active Smartrr subscriptions via their API to prevent double-billing.  
    ​
    
4.  Share a detailed migration report, including a **1:1 mapping** of subscriptions between Smartrr and Loop.  
    ​
    
5.  Ask you to review and spot-check a few contracts to confirm data accuracy.  
    ​
    
6.  Finalize the migration once you confirm everything is correct.  
    ​
    

If you need custom migration changes (e.g., price updates, variant swaps), let us know at least 7 days in advance so we can prepare.
