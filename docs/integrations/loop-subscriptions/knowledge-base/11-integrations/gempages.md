Learn how to integrate Loop with GemPages to display subscription widgets seamlessly on custom, high-converting Shopify product pages.

**GemPages** is a powerful drag-and-drop page builder for Shopify that allows merchants to create stunning, high-converting landing pages, product pages, and store layouts without any coding. It empowers store owners to design custom, mobile-responsive pages that boost conversions and enhance the shopping experience.

### Key features:

1.  **Drag-and-drop editor**: Easily create and customize pages with an intuitive, no-code editor.
    
2.  **Mobile-responsive design**: Ensure your store looks great on all devices with fully responsive templates.
    
3.  **Conversion-focused elements**: Access pre-built elements like countdown timers, pop-ups, and product sliders to increase sales.
    
4.  **Seamless integrations**: Integrate with tools like Klaviyo, , and Google Analytics to track and optimize performance.Judge.me
    

This article will walk you through the steps required in order to integrate GemPages With Loop. Once you've integrated with GemPages, the widget will be visible on your Product page.

* * *

# Integrating Loop widget V2 on GemPages product page

## Prerequisites

*   Product pages must be created in GemPages.
    
*   Products must be linked to a Selling Plan.
    
*   GemPages version 7 is required.
    

## Setting up Loop widget on product pages

1.  Open GemPages app from your Shopify store  
    ​
    
2.  Head over to the Product Page where you want to display the Loop widget.  
    ​
    
3.  In the gempages page builder, under integrations select **Shopify app**. Drag the Shopify app and place it above the add to cart button.

## Prerequisites

*   Product pages have to be set up in GemPages
    
*   Install the loop snippets
    
*   The product has to be mapped to a Selling Plan

*   Go to your Product Page

# FAQs

#### How to resolve the error that I am getting while using gempages: "Liquid error (snippets/gp-section-590767785240429224-0 line 358): Could not find asset snippets/loop-subscriptions.liquid"?

The error message "Liquid error (snippets/gp-section-590767785240429224-0 line 358): Could not find asset snippets/loop-subscriptions.liquid" indicates that the Liquid template is trying to reference a snippet file named loop-subscriptions.liquid, but it cannot find it in the theme's snippets directory.  
​  
To resolve this issue, ensure that the loop\_subscriptions.liquid file is correctly uploaded to the snippets folder of your theme. You can follow these steps:  
1\. Go to your Shopify admin panel.  
2\. Navigate to Online Store > Themes.  
3\. Click on Actions > Edit code for your current theme.  
4\. In the Snippets directory, check if loop\_subscriptions.liquid exists. If it does not, you will need to upload it.  
​  
If you are trying to install the Loop widget, make sure you have followed the installation steps correctly, including downloading and uploading all necessary files, such as loop\_subscriptions.liquid, loop\_loader.liquid, and others, as specified in the installation guide
