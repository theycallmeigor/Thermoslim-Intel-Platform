Learn how to integrate Rivo Loyalty with Loop to enable personalized rewards, referrals, and memberships that drive repeat purchases and retention.

**Rivo** is a powerful platform designed to help brands convert one-time buyers into repeat customer.

### **Key features**

*   Personalized accounts that drive retention
    
*   Fully extensible Loyalty built to scale
    
*   Turn first purchases into organic Referrals
    
*   Unlock repeat purchases and growth with memberships  
    ​
    

Rivo.io integration is available exclusively on the Loop Pro plan.

* * *

# Integration details

## How does Rivo.io work with Loop

This integration enables your customers to apply discount codes that are generated by Rivo for both initial subscription purchases and recurring subscription orders

### Prerequisites

*   You should have an active Rivo account. If not, please create from [here](https://www.rivo.io/).
    

## How to connect Loop with Rivo

### Generating Rivo API token
