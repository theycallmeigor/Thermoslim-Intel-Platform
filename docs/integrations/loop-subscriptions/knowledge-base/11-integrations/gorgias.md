Learn how to integrate Gorgias with Loop to manage subscription-related support directly within your helpdesk and improve customer service efficiency.

Gorgias is a popular Shopify helpdesk app helping brands provide exceptional customer service by centralizing all support tickets (email, chat, social media, etc.) in one place. In this article, you'll learn how to integrate Gorgias with Loop Subscriptions.  
​

Gorgias integration is available exclusively on the Loop Pro plan.

* * *

# Gorgias and Loop integration

Loop seamlessly integrates with Gorgias, empowering your brand to provide exceptional customer service to subscribers. With this integration, all support tickets are centralized, and subscription data is automatically mapped to the subscriber’s email for a more efficient and personalized support experience. Your team can manage subscriptions effortlessly within the Gorgias UI, unlocking key features such as:

# Key features

1.  **Subscription Data at a Glance**: View subscriber subscription details directly in Gorgias, mapped against their email.
    
2.  **One-Click Actions**: Send login links and payment update emails to subscribers without leaving Gorgias.
    
3.  **Seamless Subscription Management**: Perform quick actions like skipping or placing an order, reactivating, resuming, pausing, or canceling subscriptions—all within Gorgias.
    
4.  **Cancellation Insights**: Select a cancellation reason (configured in Loop) directly in Gorgias, ensuring accurate cancellation analytics in Loop.
    

# Setting up Gorgias integration

Loop has a deep integration with Gorgias that requires no API key setup on either platform, making it seamless and hassle-free. Follow these steps to connect:

1.  Make sure you have an active Gorgias account linked to your Shopify store. If you haven’t set it up yet, you can install Gorgias directly from the [Shopify App Store](https://apps.shopify.com/helpdesk) to get started.  
    ​
    
2.  Navigate to **Gorgias > Settings > All apps** & search for Loop in the search bar.

*   In your Gorgias account, go to integrations and select Loop Subscriptions.
    
*   Click Add Loop Subscriptions and allow the necessary permissions required to complete the installation.
