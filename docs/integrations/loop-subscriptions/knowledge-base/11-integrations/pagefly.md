Learn how to integrate Loop with PageFly to display subscription widgets on custom Shopify pages and boost conversions with flexible design control.

PageFly is a powerful, user-friendly page builder for Shopify, enabling you to design and customize your store with ease. With its drag-and-drop editor, extensive template library, and SEO-friendly features, PageFly is perfect for creating responsive, high-converting pages that enhance your store's performance and visual appeal.

In this article, you'll learn how to integrate Pagefly with Loop Subscriptions. Once you've integrated with Pagefly, the widget will be visible on your Product page

* * *

# Prerequisites

*   Product pages have to be set up in Pagefly
    
*   Install the loop snippets - Step 1 of Loop Widget Installation
    
*   The product has to be mapped to a Selling Plan
    

# Setting up the Loop widget (v2) in Pagefly

There are three simple steps to achieve this.

1.  Add app block container to desired PageFly pages
    
    *   Navigate to PageFly > Pages > Select page > Add "**App block**" from third-party elements.
        
    *   Drag and drop app block to desired location on page.

# Setting up the Loop widget (v1) in Pagefly

*   Open Pagefly from your Shopify Apps
    
*   Go to your Product Page
    
*   Select the Product on which you want to display the Loop Widget
    
*   In the elements section, Search for "**Liquid**" and drag and drop it where you want the Widget to be placed  
    ​
    
    [![](https://downloads.intercomcdn.com/i/o/kmcpsev1/1812395295/b3a3cd8521b45b75303a728ab623/original?expires=1774894500&signature=fda322d366186be980e0ae9052921725fb31568efdd697106658c187d8b79265&req=dSgmFMp3mINWXPMW1HO4zZCj3z7Lz1DGOnR3MUYbeRbYi3EvnvD0QZ1nGboA%0A1SVU%0A)](https://downloads.intercomcdn.com/i/o/kmcpsev1/1812395295/b3a3cd8521b45b75303a728ab623/original?expires=1774894500&signature=fda322d366186be980e0ae9052921725fb31568efdd697106658c187d8b79265&req=dSgmFMp3mINWXPMW1HO4zZCj3z7Lz1DGOnR3MUYbeRbYi3EvnvD0QZ1nGboA%0A1SVU%0A)
    
*   Click on the placed box and click on "**Open Code Editor**" on the right pane.  
    ​
    
    [![](https://downloads.intercomcdn.com/i/o/kmcpsev1/1812395310/b4f18f7f364d58fc62fa438e4bc2/original?expires=1774894500&signature=ee86e83848bfe8149424ff757e0bbb36c72dc72ced47d156d8bd3d762a39ad9d&req=dSgmFMp3mIJeWfMW1HO4zUfW8lJcjZDd1AzlkfkS1xi3q9UeiZo4witai%2F08%0Ah7i9%0A)](https://downloads.intercomcdn.com/i/o/kmcpsev1/1812395310/b4f18f7f364d58fc62fa438e4bc2/original?expires=1774894500&signature=ee86e83848bfe8149424ff757e0bbb36c72dc72ced47d156d8bd3d762a39ad9d&req=dSgmFMp3mIJeWfMW1HO4zUfW8lJcjZDd1AzlkfkS1xi3q9UeiZo4witai%2F08%0Ah7i9%0A)
    
*   In the window that opens up, insert this code

*   Click Save to save your changes
