# Troubleshooting widget issue

A checklist for when the Loop widget is not appearing on the product page.

### Prerequisites

*   Using a Shopify 2.0 theme.
*   The product page template supports app blocks.
*   The widget status is set to **"Enabled"**.

### General Checks

*   Master switch in Loop Admin is **ON**.
*   The widget is mapped to the correct theme and template.
*   The app block is not hidden in the Shopify theme editor.

### Product Checks

*   The product is **Active** (not a draft).
*   The product is mapped to a selling plan in **both** Loop and Shopify.

### Common Conflict

*   **Duplicate Names:** Two plans named identically (e.g., "Subscribe & Save") can cause one to be hidden by Shopify's internal grouping.
