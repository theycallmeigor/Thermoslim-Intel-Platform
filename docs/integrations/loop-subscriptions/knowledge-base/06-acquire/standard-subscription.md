# Standard subscription

Recurring deliveries (e.g., every 2 weeks or monthly) with payments on the same cycle.

### Setup Steps

1.  Navigate to **Loop > Acquire > Selling plans > Create selling plan**.
2.  Define name, frequencies, and discounts.
3.  Map products to the selling plan.
4.  Configure availability settings (Storefront, Portal, Admin, Checkout).

### Testing

Select "Subscribe" on the product page, choose a frequency, and complete checkout. A subscription is created in the Loop admin.
