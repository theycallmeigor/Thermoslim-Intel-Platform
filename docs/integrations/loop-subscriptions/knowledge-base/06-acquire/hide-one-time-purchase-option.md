# Hide one-time purchase option

Allows brands to make products "subscription-only" to promote recurring revenue.

### Prerequisites

*   Loop widget must be installed.
*   Product must be mapped to a selling plan.

### Steps in Shopify Admin

1.  Open the **Product editor**.
2.  Scroll to the **Purchase options** section.
3.  Check the box: **"Only sell this product as a subscription"**.
4.  Save the product.

The storefront widget will now only show subscription frequencies, removing the one-time purchase choice.
