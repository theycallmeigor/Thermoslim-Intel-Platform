# Gift subscription set up guide

Step-by-step guide for configuring and customizing gift subscriptions.

### Configuring Gift Programs

*   Navigate to **Gifts > Programs** in Loop admin.
*   Configure naming, purchase options, discounts, and shipping.
*   Enable/disable product swaps for gift recipients.

### Setting up the Gift Widget

*   Use the **Shopify app block** on product pages.
*   Add the block in the Shopify theme editor and map it to relevant product templates.
*   Customize styles and texts in the widget configuration.

### Gifting Experience Preferences

*   Schedule delivery for the first order.
*   Set recipient permissions (reschedule, order notes).
*   Enable portal features like thanking the gifter and message banners.

### Automate Product Swaps

Use Loop flows to automatically change products for each gift order milestone (e.g., rotating gift items).
