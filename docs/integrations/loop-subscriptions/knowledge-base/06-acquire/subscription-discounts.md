# Subscription discounts

Loop discounts serve as the "base price" for subscriptions; Shopify discounts can be stacked on top.

### Loop Discounts

*   **Standard:** Single fixed discount (Fixed amount, %, or Set price).
*   **Tiered:** Varies by order count (e.g., $20 off the 1st order, then $10 off thereafter).
*   **Free Shipping:** Configured through Loop shipping profiles.
*   **Loop Flows:** Complex discount journeys (e.g., 10% off after order #3, 20% off after order #6).

### Shopify Discounts

Supports native Shopify discounts such as "Amount off products," "Amount off orders," and "Free shipping" codes that apply to the subscription price.
