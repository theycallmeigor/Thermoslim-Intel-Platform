# Prepaid subscription

Customers pay upfront for multiple deliveries (e.g., pay for 30 deliveries at once).

### Benefits

*   Higher retention.
*   Increased LTV.
*   Loop generates a new order for each delivery to avoid Shopify fulfillment issues.

### Setup

1.  Check **"Is this a prepaid selling plan?"** in the selling plan editor.
2.  Set **"Charge every"** to the number of orders paid together.
3.  Map products to the plan.

### Limitations

*   Cannot be manually created in portals.
*   No upsell support.
*   Fixed amount discounts only at checkout.
*   No bundles or free item swaps.
