# Managing Shopify checkout translations

Allows merchants to update subscription-related texts on the checkout page (Shopify Plus stores).

### Common Customizations

*   **Recurring subtotal:** Change the label to "Subscription recurring subtotal" by searching for "recurring" in theme content.
*   **Dynamic pricing:** Change labels like "$47.50 every month" using variables like `{{ interval }}`.
*   **Multi-tier policies:** Update descriptions for tiered plans (e.g., "First payment $X, then $Y every 2 months").

### Location in Shopify Admin

1.  **Online store > Themes**.
2.  Click the three dots on the live theme.
3.  Select **Edit default theme content**.

Non-Shopify Plus stores have restrictions on editing certain "Recurring subtotal" labels.
