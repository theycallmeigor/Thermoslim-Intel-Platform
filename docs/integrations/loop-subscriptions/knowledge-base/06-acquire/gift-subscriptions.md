# Gift subscriptions

Allows customers to buy prepaid, time-bound (non-renewing) subscriptions for others.

### Key Highlights

*   **Recipient Notifications:** Immediate or scheduled (e.g., on a birthday).
*   **Personalization:** Include a message with the gift.
*   **Customer Experience:** Gifter checks **"This is a gift"**, provides recipient info, and completes checkout.
*   **Recipient Experience:** **"Unbox your gift"** portal page with options to thank the gifter and manage the subscription (reschedule or swap).

### Considerations

*   Available on **Shopify Plus + Loop Pro** plan only.
*   Gifts are **prepaid** and **non-renewing**.
*   Recipients cannot change the delivery frequency set by the gifter.
