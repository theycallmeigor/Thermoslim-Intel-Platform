# Gift subscription notifications

Automated email notifications specifically for gift subscriptions.

### Access

Navigate to **Loop admin > Gifts > Notifications**.

### Notification Types

*   **For Gifter:** "Thanks" message from recipient, Gift purchase confirmation.
*   **For Recipient:** Gift received, Upcoming gift order, Gift completion.
*   **For Admin:** New gift subscription created.

### Customization

*   **HTML Editor:** Full template customization.
*   **Variables:** Use `{{gifter_name}}`, `{{recipient_first_name}}`, `{{subscription_total_price}}`, and `{{customer_portal_link}}`.
