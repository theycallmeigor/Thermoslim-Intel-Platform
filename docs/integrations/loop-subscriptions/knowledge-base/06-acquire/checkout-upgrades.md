# Checkout upgrades

Converts one-time buyers into subscribers at checkout with a single click.

### Prerequisites

*   Shopify Plus store.
*   Loop Starter or Pro plan.

### Setup

1.  **Customize Widget:** Navigate to **Acquire > Checkout upgrades** in Loop.
2.  **Plan Availability:** Ensure selling plans are active for "Checkout".
3.  **Checkout Editor:** Add Loop app blocks (**"Upgrade to subscription"** and **"Upgrade banner"**) in the Shopify checkout editor.
4.  **Enable:** Turn on the widget in Loop admin.

### Logic

*   **Single Product:** Automatically fetches the highest priority selling plan.
*   **Multiple Products:** Displays common frequencies; defaults to the fastest frequency.

Excludes prepaid plans, $0 items, and bundle components.
