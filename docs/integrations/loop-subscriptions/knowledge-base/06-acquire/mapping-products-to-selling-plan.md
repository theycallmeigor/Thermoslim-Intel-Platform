# Mapping products to selling plan

Ensures subscription logic (frequency, billing, discounts) is applied to the correct products or collections.

### Mapping Types

*   **Product Mapping:** Add individual products directly to a selling plan.
*   **Collection Mapping:** Map whole Shopify collections to a plan. Supports smart collection auto-syncing (updates as products are added/removed from Shopify collections).

Mapping enables the subscription options to appear in the storefront widget for the associated products.
