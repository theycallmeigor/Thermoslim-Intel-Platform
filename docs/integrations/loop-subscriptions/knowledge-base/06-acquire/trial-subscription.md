# Trial subscription

Allows risk-free testing before converting to a paid plan.

### Method 1: Dynamic Discounts

Configure a single selling plan with a 100% discount for the first cycle, changing to 0% for subsequent payments.

### Method 2: Loop Flows (Pro Plan)

1.  Create a $0 trial product and a full-size product.
2.  Create separate selling plans for each.
3.  Set up a Flow: Trigger on **"New subscription created"**.
4.  If the trial product is present, **Swap product** to full-size and **Change plan** to the paid version.

Billing starts automatically after the trial period (e.g., 7 days).
