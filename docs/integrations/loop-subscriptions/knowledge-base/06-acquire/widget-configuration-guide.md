# Widget configuration guide

Detailed customization options for the Loop storefront widget.

### Configuration

*   **Layouts:** Choose from Radio groups, Dropdowns, Buttons, or Checkboxes.
*   **Default Selection:** Set the initial choice to One-time or Subscription.
*   **Pricing:** Configure discount badges and strikethrough prices.
*   **Popup:** Enable "Subscription details" for customer info.

### Styling

Customize background colors, borders, width, corner radius, margins, and padding to match your brand.

### Texts

Edit all public labels, including "Subscribe & Save," "One-time purchase," and frequency descriptions.
