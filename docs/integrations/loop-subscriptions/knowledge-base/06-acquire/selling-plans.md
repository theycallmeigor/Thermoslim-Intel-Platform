# Selling plans

A selling plan defines the billing and delivery frequencies for subscription products.

### Key Features

*   **Order Schedule:** Define frequencies in days, weeks, or months.
*   **Discounts:** Fixed, Percentage, or Set price.
*   **Anchor Day Billing:** Charges on specific days (e.g., 1st of month).
*   **Advanced Options:** Min/Max billing cycles and plan descriptions.
*   **Availability:** Control visibility across Storefront, Portals, and Checkout.

### Subscription Models Supported

*   Standard
*   Prepaid
*   Gift
*   Build a bundle
*   Trial
*   Membership
