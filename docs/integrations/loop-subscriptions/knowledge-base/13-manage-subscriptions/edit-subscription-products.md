# Edit subscription products

Loop provides a powerful editor for active subscriptions, allowing admins to modify items and pricing.

### Key Actions

*   **Edit Existing Product:** Change quantity, base price, or discount amounts.
    *   *Base Price:* Change the price within the subscription (does not affect Shopify catalog).
    *   *Discount Amount:* Set specific discounts, including those that apply after a certain number of payments.
*   **Replace Product:** Swap an item with another from the catalog.
*   **Delete Product:** Remove an item (minimum of two products required in the subscription to delete one).
*   **Add Product:** Include new items as one-time or recurring additions.
*   **Add Discount:** Apply manual discounts.
