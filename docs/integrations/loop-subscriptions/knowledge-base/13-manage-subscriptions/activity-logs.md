# Activity logs

Learn how to use activity logs in Loop to track subscription actions, ensure transparency, and maintain a complete audit trail for every event.

## Overview

The Activity logs provides a detailed timeline of all actions taken on a subscription. It helps brands track events such as:
- Cancellations
- Pauses
- Merges
- Product swaps
- Address changes
- Execution of flows

Each log entry captures:
- **Exact date and time** of the action
- **Who performed it** — whether triggered by an admin or initiated by the subscriber through the customer portal

This visibility helps ensure transparency, troubleshoot issues efficiently, and maintain a clear audit trail for every subscription journey.

## Accessing activity logs in Loop

1. Navigate to Subscriptions > Search for the customer's "Subscription ID" in the Subscriptions tab
2. Once the subscription page is opened, scroll down to view the **Activity log**, which lists actions in reverse chronological order (newest to oldest)
