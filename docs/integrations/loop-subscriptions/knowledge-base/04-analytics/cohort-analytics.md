# Cohort analytics

Focuses on the upgraded Cohort analytics dashboard designed for long-term visibility into subscriber behavior (up to 36 months). It allows merchants to analyze retention and churn at both monthly and order-level precision.

### Key Features

*   **10+ cohort metrics:** AOV, revenue, order count, etc.
*   **Timeframe:** Extended 36-month timeframe.
*   **Milestones:** Order-level breakdowns (1st, 2nd, 3rd order milestones).
*   **Metrics:** Subscriber retention, subscriber orders placed, average cumulative orders, revenue realized, and average subscriber LTV.
