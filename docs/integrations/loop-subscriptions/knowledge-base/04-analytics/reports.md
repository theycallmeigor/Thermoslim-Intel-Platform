# Reports

Explains how to access and generate detailed data exports for back-office operations and rapid analytics.

### Types of Reports

*   **Subscriptions Report:** Comprehensive subscription data.
*   **Inventory Forecast:** SKU-level forecasting.
*   **Subscription Activity Logs:** Detailed event history.
*   **Product Acquisition Report:** Tracking acquisition performance.

### Functionality

*   Apply filters (status, product, order count).
*   Export to Excel/CSV.
*   Use cases: Exporting email lists, tracking flow impact, resolving discrepancies.
