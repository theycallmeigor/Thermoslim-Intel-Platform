# Payment analytics V2

An advanced version of payment analytics that segments performance into three stages: First attempt, First recovery cycle, and Subsequent recovery cycles.

### Segmentation Logic

1.  **First attempt:** Initial attempt when not in dunning.
2.  **First recovery cycle:** Retries within the same order cycle.
3.  **Subsequent recovery cycles:** Delayed recoveries in dunning.

### Key Metrics

*   **Payments Snapshot:** Attempted, Success, Recovered, Under Recovery, and Lost (Last 90 days).
*   **Payment Source Distribution:** Shop Pay, PayPal, etc.
*   **Recovery Analytics:** Detailed breakdown by retry number (1-15) and failure reason.
