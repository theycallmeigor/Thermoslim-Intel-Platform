# Account log
Learn how to use account logs in Loop to monitor user activities, enhance security, and maintain accountability across your account operations.
Managing a digital platform involves keeping track of various user actions to ensure security, accountability, and smooth operations. This is where Account Logs come into play. The Account Logs feature in Loop allows you to track and review user activities within your account. Each log includes detailed information such as timestamps, usernames, actions performed, and brief descriptions.

# Where to find account logs
Go to settings. Navigate down to Account log under Admin section.

# Access account logs
1. Account logs enables you to track a record of user activities within Loop, including timestamps, usernames, actions performed, and brief descriptions.
2. You can review activities for a specific date range and search for users by email address and specific activities.
3. Logs can also be exported with the current set of filters using “Export” button.
