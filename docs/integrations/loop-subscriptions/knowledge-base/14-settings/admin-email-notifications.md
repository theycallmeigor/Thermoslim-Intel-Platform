# Admin email notifications

Learn how to configure admin email notifications in Loop to stay updated on key subscription events like signups, cancellations, and payment failures.

Loop subscriptions provides automated email alerts to keep brands informed about key subscription activities, such as new signups, cancellations, and payment failures. These notifications help brands stay on top of their subscription operations and respond quickly to important events, ultimately ensuring a smoother experience for both the team and the customer.

## How to access the admin email settings?

Admin email notifications can be accessed by navigating to **Settings > Notification**. Each email can be enabled or disabled individually based on your business requirements.

You can add multiple email addresses to receive admin notifications, ensuring that all relevant team members stay informed about key subscription events.

Admin email notifications are non-editable and follow a fixed format configured in the backend system.

## Types of admin email notifications

The following Admin email notifications are available in Loop and are triggered based on specific subscription events, as outlined below.

| Notification | Action |
| --- | --- |
| New subscription | Sent to the admin when a new subscription order is placed |
| Subscription rescheduled | Sent to the admin when a subscription is rescheduled |
| Subscription delayed | Sent to the admin when a subscription is delayed |
| Subscription paused | Sent to the admin when a subscription is paused |
| Subscription resumed | Sent to the admin when a subscription is resumed |
| Subscription marked for cancellation | Sent to the admin when a prepaid subscription is marked for cancellation |
| Subscription cancelled | Sent to the admin when a subscription is cancelled |
| Subscription reactivated | Sent to the admin when a subscription is reactivated |
| Subscription expired | Sent to the admin when a subscription is expired |
| Order skipped | Sent to the admin when an upcoming order is skipped |
| Order unskipped | Sent to the admin when an order is unskipped |
| Order partially billed | Sent to the admin when a subscription order is partially billed due to few items being out of stock |
| Product out of stock | Sent to the admin when a subscription order is delayed or skipped due to items being out of stock |
| Payment failed with retries left | Sent to the admin when a subscription payment fails and will be automatically reattempted |
| Last payment retry left | Sent to the admin when a subscription payment fails and only one retry is remaining |
| Payment failed | Sent to the admin when a subscription payment fails after the final retry or retry is not enabled |
| Card expiring | Sent to the admin when a customer card is about to expire. Emails will be sent out at 30, 15, and 3 days before card expiry date |
| Products changed | Sent to the admin when subscribed products are modified by the customer |
| Subscription delivery address updated | Sent to the admin when delivery address is updated for a subscription |
