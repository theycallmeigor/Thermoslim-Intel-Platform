# User permissions & role management
Learn how to manage users and permissions in Loop to control access, assign roles, and maintain security within your subscription operations.
Managing users & permissions is key to maintaining security and efficiency in Loop Admin. By assigning specific roles and access levels, you ensure that the right people can perform necessary tasks while safeguarding your store against unauthorized or unintended actions.
User permissions control what tasks users can perform and which features they can access within the Loop admin. This article covers the different user roles, how to manage permissions, how to create or update roles, and how to add or edit user access.
"Users & permissions" is available exclusively on the Loop Pro plan.

# Default user roles
Loop provides three default user roles, each offering different access levels within the Loop portal.
- Owner: Has full access to all features and settings, including managing both Admin and other roles users. This role is automatically assigned to the email linked with your Shopify store and cannot be edited.
- Admin: Granted full platform access and can manage Member-level permissions. and change their roles. This role is also non-editable.
- Member: Has view-only access by default. Owners and Admins can assign additional permissions as needed.

#### Why is collaborator access needed, and where can I find the collaborator access code?
Collaborator access is needed to allow the Loop support team to directly investigate and troubleshoot issues within your Shopify store without the need for continuous back-and-forth communication with the store owner. This helps speed up resolution and ensures a smoother support experience.Sometimes, store owners are required to share a Collaborator access code, which can be found in Shopify > Settings > Users and Permissions > Collaborator Request Code.Once this code is shared with the support team, Loop will send a collaborator access request, which you can approve by going to:​Shopify > Settings > Users and Permissions > Collaborator Accounts, then find "Loop Subscriptions" and approve the request.

#### How can I grant 'Loop Admin' access to internal users so they can manually manage subscriptions - such as creating new ones, cancelling, applying discounts, or updating shipping and delivery details?
To grant 'Loop Admin' access to internal users so they can manually manage subscriptions (create, cancel, apply discounts, update shipping, etc.), please follow the steps below:​​On Shopify:Go to Shopify Admin > Settings > Users and permissions > Add staff.After adding the staff member, click on their profile.In the App permissions section, enable access to the Loop Subscriptions app.Ask the staff member to log in and open the Loop app from their Shopify profile. This action will create their member profile inside Loop Admin.Once the profile is created, the store owner can assign roles and permissions within the Loop portal.​​On Loop:Navigate to Loop > Settings > User Permissions.Click Edit next to the user's name and assign the required permissions or role (e.g., Admin).This process ensures your internal users have the appropriate access to manage subscriptions effectively.
