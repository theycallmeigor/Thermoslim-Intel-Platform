# Personalized swap profiles

Allows brands to show curated product recommendations when a subscriber chooses to swap instead of cancel. This reduces decision fatigue and increases retention.

### Configuration

1.  Navigate to **Loop > Retain > Product Swaps > Create personalized swap profile**.
2.  Choose **Profile availability** (Product swaps, Cancellation swaps, or Both).
3.  Define **Conditions** (subscription type, product ID, customer tag).
4.  Choose **Product display options**:
    *   Group by products (product first, then variants).
    *   Show variants directly (all variants upfront).
5.  Map products and set discount preferences.

### Logic

Loop checks for an active personalized profile matching the product or condition. If found, it shows the curated list; otherwise, it defaults to the general swap profile.
