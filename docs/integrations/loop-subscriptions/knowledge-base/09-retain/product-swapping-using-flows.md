# Product swapping using flows

Automates the transition from one product to another based on milestones (e.g., starter kit to refill).

### Examples

*   Coffee machine (1st order) to coffee beans (subsequent).
*   Razor handle to blades.

### Setup Guide

1.  **Trigger (When):** "A new subscription is created".
2.  **Condition (If):** "Product in subscription" is the starter pack.
3.  **Action (Then):** "Swap product" (Old: Starter, New: Refill).

### Subscriber Experience

The customer buys the starter pack, the flow triggers immediately, and the portal updates to show the refill product for the next delivery.
