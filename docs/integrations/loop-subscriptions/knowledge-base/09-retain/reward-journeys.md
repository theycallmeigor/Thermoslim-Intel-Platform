# Reward journeys

Milestone-based rewards to celebrate loyalty and increase Lifetime Value (LTV).

### Configuration

1.  **Select "Reward journey"** from the "Create flow" popup.
2.  **Define conditions** (subscription, customer, demographics).
3.  **Add actions:** Add/remove discount, mystery reward, or customer tags.
4.  **Set up notifications:** Reward banner, optional email, or text in upcoming order emails.
5.  **Add multiple milestones** using "Add an order in journey".

### Customer Experience

A reward banner in the portal shows progress and upcoming milestones (discounts, gifts).

### Banner Setup

Requires desktop (3912x964px) and mobile (2000x960px) images uploaded to Shopify.
