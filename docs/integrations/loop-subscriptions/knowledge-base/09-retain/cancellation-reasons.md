# Cancellation reasons

The second layer of the cancellation flow, collecting feedback and offering tailored "treatments".

### Setup

1.  Enable in **Loop admin > Retain > Cancellation flows > Reasons**.
2.  "Add reason" and assign conditions (product, history, tags).
3.  **Treatments:** Link reasons to actions (Pause, Skip, Swap, Talk to support).
4.  **Custom Treatments:** Guide users to consultations or quizzes via external URLs.

### Customer Feedback

Collect final insights if the customer proceeds to cancel.

### Internal Use

Create admin-only reasons by applying conditions customers won't meet (e.g., non-existent tags).
