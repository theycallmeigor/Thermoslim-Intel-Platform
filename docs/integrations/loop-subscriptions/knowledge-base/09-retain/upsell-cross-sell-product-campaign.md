# Upsell/Cross-sell product campaign

Highlights exclusive products or deals in the Customer portal to increase Average Order Value (AOV).

### Campaign Setup

1.  Navigate to **Loop Admin → Campaigns → Create Campaign → Upsell/Cross-sell Product**.
2.  Choose audience (All active or filtered).
3.  Select channels (Customer Portal banner, Email/SMS, or both).
4.  Select products to promote and add banner images (Desktop: 3912x964px, Mobile: 2000x960px).
5.  Customize offer labels and set timeline.

### Customer Experience

Subscribers see banners in the portal; clicking opens an offer drawer where they can add products as a subscription or one-time add-on.

### Using Loyalty Points

Merchants can allow customers to pay with loyalty points, showing lower visible prices to boost engagement.
