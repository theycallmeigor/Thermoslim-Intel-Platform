# Streaks

The Streaks feature gamifies the subscriber journey by rewarding customers who consistently place their subscription orders on time. It aims to build habits and increase the number of successful recurring orders.

### Streaks Overview

*   Customers unlock milestone rewards (discounts, gifts, or perks) by maintaining a consistent order rhythm.
*   Encompasses a scheduled order date plus a configurable grace period.

### Setting up Streaks

1.  Navigate to **Loop > Retain > Streaks > Create streak**.
2.  Define streak length, grace period, and enrollment conditions (subscription, product, customer).
3.  Configure rewards and custom banners.
4.  Publish by setting status to "Active".

### Customer Experience

*   Subscribers are automatically added to relevant programs.
*   A streak banner tracks progress in the customer portal.
*   Skipping, pausing, or rescheduling does *not* break the streak; only missing the grace period does.

### Analytics

Tracks metrics like Enrolled, Ongoing, Success, Failed, and Success Rate.
