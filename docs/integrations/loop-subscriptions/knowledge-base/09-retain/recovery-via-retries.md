# Recovery via retries

Built-in payment recovery featuring smart predictive logic to reclaim revenue from failed/declined cards.

### Configuring Retry Settings

1.  Navigate to **Loop > Retain > Payment recovery**.
2.  Set **number of retry attempts** and **days between retries**.
3.  Choose **action after exhausted retries** (Skip, Pause, or Cancel).

### Key Settings

*   **Hard declines behavior:** Configure actions (Pause/Cancel) for specific decline reasons.
*   **Pending payments:** Set days before a pending payment is marked as failed.
*   **Customer Communication:** Personalize failure notifications and update-card button labels.

### Dunning

The automated process for handling failed payments due to expiration, insufficient funds, etc.
