# Configuring minimum order value & weight

Learn how to set minimum order value and weight in Loop to optimize fulfillment, control costs, and maintain smooth subscription operations.

To ensure smooth fulfillment and operational efficiency, brands can configure minimum order requirements in Loop — both Minimum order value and Minimum order weight. These settings prevent subscribers from modifying their upcoming orders (e.g., removing products) if doing so brings the total below the set threshold.

> Customers can still **add** products to their subscription — only removal is restricted.

## Enabling the minimum order setting

1. Navigate to **Loop admin > Customer portal > Preferences > Edit/Remove products section**
2. Enable the required minimum order setting based on your use case — value-based, weight-based, or both

## Customer portal experience

### Case 1: Minimum order value

Brand has enabled "Minimum order value" set to $100. If total order value would drop below $100, the system restricts product removal and displays an error message.

1. Subscriber logs in and clicks the "Edit" button next to the skip button
2. Clicks the Remove button
3. An error message is displayed as soon as the subscriber selects the product to remove if the total order value would fall below the defined threshold

### Case 2: Minimum order weight

Brand has enabled "Minimum order weight" set to 10g. If total order weight would drop below 10g, the system restricts product removal and displays an error message.

1. Subscriber logs in and clicks the "Edit" button next to the skip button
2. Clicks the Remove button
3. An error message is displayed as soon as the subscriber selects the product to remove if the total order weight would fall below the defined threshold
