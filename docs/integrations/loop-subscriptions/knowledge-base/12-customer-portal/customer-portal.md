# Customer portal

Learn how Loop's customizable customer portal empowers subscribers to manage their subscriptions effortlessly while enhancing retention and brand experience.

The customer portal is a powerful tool to help you manage, retain, and grow your subscription business. It's the place where your subscribers can take key actions, like skipping an order, adding one-time items to their next delivery, updating their delivery address, adding discount codes, and a lot more.

With Loop subscriptions, you get an insanely customizable and personalizable customer portal, built with smartphones in mind. The customer portal is fast, responsive, and quick to support your brand missions.

## Customer portal preferences

Navigate to **Loop admin > Customer portal > Preferences** to configure these settings.

| Preference | Description |
|-----------|-------------|
| Create subscription | Allow subscribers to create new subscriptions directly from the portal |
| Apply discounts | Let subscribers apply discount codes (including multiple ones) |
| Edit billing/delivery schedule | Enable subscribers to edit billing/delivery intervals and auto-recalculate discounts |
| Charge on resume | Trigger charge immediately when a subscription is resumed |
| Reactivate subscription | Allow subscribers to reactivate cancelled subscriptions |
| Merge subscriptions | Let customers merge subscriptions to save on shipping costs |
| Add/edit order notes | Allow customers to see and edit notes on subscription orders |
| Pause subscription | Allow pausing/resuming subscriptions from the portal |
| Pause subscription intervals | Add available pause durations with custom durations & smart pause logics |
| Place order | Enable subscribers to place the upcoming order immediately |
| Skip order | Let subscribers skip upcoming orders with optional consecutive skip limits |
| Gift order | Allow customers to gift their upcoming order without affecting future orders |
| Delay order | Allow subscribers to delay an order while maintaining consistent intervals |
| Reschedule order | Give subscribers control to reschedule orders within a defined interval |
| Last order details | Show last order date to help avoid duplicate orders |
| Edit/remove products | Let subscribers remove products one-time, entirely, or change quantity |
| Minimum order value | Prevent product removal if order value goes below the configured minimum |
| Minimum order weight | Allow removal only if total weight is above the minimum configured value |
| Show unlisted products | Show unlisted products in upsell, swap, and create subscription flows |
| Update payment method | Let subscribers update payment methods |
| Change payment method | Allow switching between multiple saved payment methods |
| Update delivery address | Let subscribers update their delivery address from the portal |
| Change pickup location | Enable subscribers to select a different pickup location |
| Change delivery method | Let subscribers switch between shipping, pickup, or local delivery |
| Prepaid subscription price texts | Choose whether to show per delivery or total prepaid cycle price |
| Maximum orders per day | Set a limit on the number of orders allowed per subscription each day |
| Maximum quantity per item | Restrict how many units of a product can be added or updated |

## Accessibility

Enable the passwordless subscription login page and add it to your Shopify store's header. Navigate to **Loop admin > Customer portal > Accessibility**. Copy the Subscription login page URL and paste it in your store header as a "Manage subscriptions" button.

## Themes and customization

Create different themes and publish them with one click (for BFCM, Christmas, special occasions). Customize via **"Customize button"**:

1. **Layout settings**: Customize skeleton of "Subscription listing page" and "Subscription details page" via drag and drop. Add variables based on customer, store, or subscription properties.
2. **Styles settings**: Customize colors of every piece on the portal; add custom CSS.
3. **Custom JS section**: Add JS code to extend functionality (e.g., hide edit button from certain provinces).
4. **Texts settings**: Edit every piece of text on the portal — button labels, success messages, action-related text.

## Growth features

- **Cancellation flows**: Reduce cancellations with retention flows before a subscriber cancels
- **Upsell**: Offer personalized upsell/upgrade options with granular customizations by subscriber cohorts

## FAQs

**Why is the customer portal not loading?**
You may not have any active subscriptions. Create a test subscription from the admin portal to preview. If still not working, create a 100% manual discount on Shopify and apply it during a test purchase.

**How can I stop customers from cancelling through the portal?**
Go to Loop > Settings > Customer Portal > Order Actions and disable cancellation.

**What are the methods to access the Customer Portal?**
1. "Manage Subscription" button on the Shopify Account Page
2. Subscription Login Page (Magic Link via Email) — enable at Loop > Customer Portal > Accessibility

**How long does the magic link stay active?**
- Token expiry: 48 hours if not clicked
- If clicked within 48 hours: generates a 30-day long-lived token per device/browser
- Tokens are unique per customer and session

**Can customers without an active subscription access the portal?**
Yes — customers can access the portal even if their subscription is active, paused, cancelled, or expired.
