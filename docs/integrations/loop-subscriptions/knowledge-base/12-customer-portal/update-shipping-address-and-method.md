# Update shipping address and method

## Prerequisites

The following settings must be enabled before a customer can change the shipping address/method from the customer portal:

Navigate to **Customer Portal > Preferences > Delivery method details** and enable the settings.

## Updating the shipping address

Once "Update delivery address" is enabled, customers will see an "edit" button in the shipping details section on their customer portal. Clicking it opens a popup with the current shipping address which can be edited.

## Updating the delivery method

To allow editing the Delivery method (Pickup/Local Delivery) from the customer portal:
- Enable the **Change Pickup location** and/or **Change delivery method** settings in the Loop app
- Once enabled, customers will be able to choose from:
  - **Choose Local** (if local delivery is set up in Shopify)
  - **Choose Pickup** (if pickup is set up in Shopify)

> These options only appear if the delivery methods are set up in the Shopify store.
